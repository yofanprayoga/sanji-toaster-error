## The error message

> ERROR: Toast.exe has stopped working. The bread is fine. You are the problem.

77 characters. A crashed program, an innocent loaf, and a user to blame — the whole joke in one read.

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, 1–120 characters, single line, no trailing whitespace). No network, no clock, no randomness — deterministic across runs.
